# よく使うレコード一覧

VCA(OMA / DCS)v3.14 で定義されているレコードのうち、通信の制御と、玉型・処方・レンズ形状に関わるものを抜き出し、日本語で説明したものです。規格には約 500 のラベルがあります。全ラベルの日本語の説明は [all-records.md](all-records.md) に、左右・単数/複数・廃止の別は [src/vca-records.js](../src/vca-records.js) に機械可読の形で入っています。意味や正確な定義は、規格書の附属書 A(表 A.1・A.1a・A.2・A.27)を見てください。

- 左右: ○ は「右眼の値;左眼の値」の 2 つを持つレコード。片眼が空欄でも区切りの `;` は省かない(受け取る側は、値が 1 つだけでも両眼に適用して受け入れるのが望ましい)。△ は左右レコードのうち、値 1 つなら両眼に適用すると規格で決まっているもの。空欄は値 1 つだけのレコード
- 文字列: limited は 12 文字まで。どの欄も 255 文字まで(v3.13 から)。literal は規格で決まった値だけで、大文字小文字を区別する
- 単位: D はディオプター。「TIND 基準」はツール屈折率(既定 1.53)で換算したカーブ値

## 通信の制御(インターフェイスレコード)

| ラベル | 左右 | 内容 |
|---|---|---|
| `REQ` | | 要求の種類(`INI`・`TRC`・`EDG` などの文字列、または初期化で割り当てられた要求 ID)。要求パケットの先頭 |
| `ANS` | | 応答の種類。要求と同じ値を返す。応答・データパケットの先頭 |
| `JOB` | | ジョブ番号(limited、12 文字まで)。初期化以外では 2 番目のレコード(`TIM`・`MNT`・`CON`・`LNF` などの例外は README の 5 章) |
| `STATUS` | | ステータスコード(0 が正常)。後ろに説明文を付けられる |
| `XSTATUS` | | 左右別の詳しいエラー・警告・通知(`R`/`L`/`B`;コード;説明;`E`/`W`/`N`)。4 番目の欄が空なら警告(`W`)。複数あってよい |
| `CRC` | | CRC-16 の値(10 進)。パケットの最後 |
| `DEV` | | デバイスの種類 |
| `VEN` | | 機器メーカーの識別子 |
| `MODEL` | | 機種 |
| `SN` | | 機器のシリアル番号 |
| `OMAV` | | 規格のバージョン(例: 3.14) |
| `DEF` / `D` / `ENDDEF` | | 自動フォーマット初期化で、受け取りたいレコードの一覧を定義する。`D` は 1 行 80 文字まで。ホストは `DEF=タグ;要求ID` で要求 ID を返す |
| `TIMEOUT` | | タイムアウトの変更(確認応答;パケット;文字間、秒。2-255)。初期化でホストから送る |
| `TXTENC` | | text・limited の欄の文字コード(`ASCII` または `UTF-8`) |
| `REM` | | 備考。処理には使わず、相手も送り返さない |
| `DRLFMT` | | 穴あけデータの基準の取り決め(`C`・`E`・`B`)。初期化(または要求パケット)で使い、データパケットには入らない |

## 玉型(トレース)

| ラベル | 左右 | 内容 |
|---|---|---|
| `TRCFMT` | | 玉型データの見出し(形式;点数;角度モード;眼;対象)。両眼なら眼ごとに 1 つ。初期化や要求パケットでは、対応できる形式を好みの順に並べる |
| `R` | | 半径(形式 1 では 1/100 mm の整数)。`TRCFMT` の直後に続く |
| `A` | | 角度(1/100 度)。角度モードが `U`・`C` のとき `R` の直後に続く |
| `ZFMT` / `Z` / `ZA` | | 玉型の立体形状(サグ)の見出し・値・角度。書式は `TRCFMT` と同じ。値は 1/100 mm で、最も前(フレーム前面側)の点が最小の正の値 |
| `HBOX` | △ | 玉型の横幅(外接箱の幅、mm) |
| `VBOX` | △ | 玉型の縦幅(外接箱の高さ、mm) |
| `CIRC` | △ | 玉型の周長(平面、mm) |
| `CIRC3D` | △ | 玉型の周長(立体、mm) |
| `FED` | ○ | 有効径。箱中心から玉型までの最長半径の 2 倍(mm) |
| `FCRV` | △ | フレームのカーブ(TIND 基準 D) |
| `DBL` | | 鼻幅(左右のレンズ間の距離、mm) |
| `MPD` | | フレーム PD(左右 HBOX の平均+DBL。ホストが補正を加えることもある) |
| `BSIZ` | △ | 玉型の大きさ補正(横幅で指定、mm)。`CSIZ` と両方に 0 以外の値を入れてはいけない |
| `CSIZ` | △ | 玉型の大きさ補正(周長で指定、mm) |
| `FBFCIN` / `FBFCUP` | ○ | 加工用ブロックの位置から玉型の中心までのずれ(mm。IN は鼻側が正、UP は上が正)。玉型を意図的にずらすときに使い、通常は 0 |
| `ETYP` | | 縁の加工の種類(-1 削らない、1 ヤゲン、2 リムレス(平)、3 溝掘り、4 ミニヤゲン、5 T ヤゲン、6 U ヤゲン。7-32 は予約、33-127 はホストと装置の間で取り決める) |
| `FTYP` | | フレームの種類(0 未定義、1 プラスチック、2 メタル、3 リムレス、4 オプチル。5-127 は予約) |
| `POLISH` | | 磨きの指定(0 磨かない、1 縁と面取り(ピンベベル)を磨く、2 面取りだけ磨く、3 縁だけ磨く。128 を足すと高光沢) |
| `BEVP` | △ | ヤゲン位置の決め方(0 手動、1 前面に沿う、2 前面からの割合、3 フレームカーブ、4 50/50、5 後面に沿う、7 機械の設定、10 フリー)。量は `BEVM`、カーブは `BEVC` |

## 穴あけ(DRILLE)

`DRILLE` は穴 1 つ(または長穴・切り欠き 1 つ)ごとに 1 レコードで、1 つのパケットに何行でも入ります(規格 5.5)。v3.04 からのレコードで、それ以前の `DRILL` は廃止されました。使う前に `DRLFMT` で基準(`C`・`E`・`B`)を取り決めます。規格は初期化での取り決めを求めていますが、初期化しない場合は要求パケットに `DRLFMT` を入れる、とも書かれています。

| 欄 | 内容 |
|---|---|
| 1 | 眼: `R`・`L`・`B`(`B` は右眼の座標で書き、左眼には左右反転して使う)。`DRILLE=0` は穴なし、`DRILLE=?` はホストが穴データに対応していない |
| 2 | 基準: `C` 箱中心、`E` 縁、`B` 外接箱、`R` グループ内の基準穴から。`E`・`B` には `N`(鼻側)か `T`(耳側)が続く。最後に取付金具の面 `F`(前面、省略時)か `R`(後面)。空欄は `C`。`0` はその眼に穴なし |
| 3・4 | 始点の x・y(mm)。穴の中心、長穴の一端、切り欠きの外側上の角 |
| 5 | 直径(長穴は幅)。空欄は機械の既定。矩形の切り欠きでは角の丸みの直径で、0 は角を丸めない(座標は丸みの円の中心を指す) |
| 6・7 | 終点の x・y。空欄なら丸穴 |
| 8 | 深さ(mm)。空欄・0 は貫通。貫通しない穴は、2 欄の取付面の側からあける |
| 9 | 種類: 1(または 0、空欄)は穴・長穴、2 は矩形の切り欠き |
| 10 | 角度モード: `F` 前面の法線、`B` 後面の法線、`A` 11・12 欄の角度。空欄なら同じグループの指定に従い、それも無ければ `F` |
| 11・12 | 横方向・縦方向の角度(度。基準は箱中心での前面の法線)。横は右眼で鼻側、左眼で耳側が正。縦は上が正 |
| 13・14 | その位置で許される最小・最大の厚み(mm) |
| 15 | グループ(`A1`、`A2` のように英字+番号。1 が基準の穴) |
| 16 | 玉型の大きさを変えたときの動き: 0 比例して動く、1 x を固定、2 y を固定 |

同じ側(鼻側・耳側)の穴は、明示しなくても 1 つのグループとして同じ角度であけます。角度モードはグループ内の 1 つの穴にだけ書けば足ります。1 つのパケットの `DRILLE` はすべて同じ基準でなければなりません。`VCA.drillFeatures()` はこれらの決まりを当てはめた結果を返します。

## データセット

決まった順序で続く複数のレコードの組です。見出しのレコードの直後に中身が続き、データセットに属さないレコードが来たら終わります。

| 見出し | 中身 | 内容 |
|---|---|---|
| `TRCFMT` | `R`、`A` | 玉型(5.4) |
| `ZFMT` | `Z`、`ZA` | 玉型のサグ。直前の `TRCFMT` に付く |
| `CRIBFMT` | `R`、`A` | 削り落とし形状(5.10)。中心は表面加工ブロックの中心 |
| `STHKFMT` | `R`、`A`、`T` | 面加工後のレンズの厚み。表面加工ブロックの中心からの半径ごとに 1/100 mm で表す(5.11) |
| `SHLFFMT` | `S`、`SA`、`SD`、`SW` | 縁の棚(段差)の形(5.8) |
| `SURFMT`・`PASSFMT` | `ZZ`、`DZY`、`DZX`、`DZXY` | フリーフォームの面形状の表と周囲の傾き(5.9.4) |
| `PMFMT` | `PP` | 度数分布の表(5.12) |
| `WMFMT` | `WW` | 検査の重みの表(5.13) |
| `DDFMT` | `DD` | 設計からの誤差(5.14) |

上の 5 つは玉型と同じ書式で、形式 1-4 を使えます。角度モードは `TRCFMT`・`ZFMT`・`SHLFFMT` が `E`・`U`・`C`、`CRIBFMT`・`STHKFMT` は `E`・`U` だけです。見出しの最初の欄が 0(例: `TRCFMT=0`)なら「データなし」です。初期化や要求のパケットでは、見出しだけが「対応できる形式の候補」として並び、ホストは使う形式を 1 つ選んで返します(どちらも中身は続かない)。ファイルの場合、玉型データは形式 1 だけです。

## 測定値の接頭辞

表 A.1 の M 欄が Y のラベルには、接頭辞を付けたレコードもあります(A.1.1.7)。O のラベルは接頭辞付きでのみ使います。

| 接頭辞 | 内容 | 例 |
|---|---|---|
| `INS` | 検査機器が測った値 | `INSADD=1.96;1.96` |
| `TOL` | 公差内かどうか(0 不合格、1 合格、9 未検査) | `TOLADD=1;1` |
| `TOLV` | 許される範囲。基準値から下限・上限までのずれを `\|` で区切る | `TOLVADD=-0.04\|0.06;-0.04\|0.06` |
| `CK` | その値を検査するか(0・1) | `CKADD=1;1` |
| `LD` | レンズ設計システムが設計した値 | `LDADD=2.00;2.00` |

## 基準点のずれを表すレコード

`FBFCIN` のように 6 文字で `IN`・`UP` で終わるレコードは、2 つの基準点の位置関係を表します(規格 5.2)。`BRERA` のように `A` で終わるものは角度です。最初の 2 文字が 1 つ目の基準点、次の 2 文字が 2 つ目の基準点で、値は「1 つ目から見た 2 つ目の位置」です。`IN` は鼻側が正、`UP` は上が正です。

| 記号 | 基準点 |
|---|---|
| `BC` | ブランクの中心 |
| `BR` | 後面刻印のレンズの、後面の隠しマークの中点 |
| `ER` | 前面の隠しマークの中点(刻印の基準点) |
| `DR` | 遠用の基準点 |
| `NR` | 近用の基準点 |
| `FB` | 玉型加工用ブロックの位置 |
| `SB` | 表面加工用ブロックの位置 |
| `FC` | 玉型(フレーム)の外接箱の中心 |
| `OC` | プリズム基準点(PRP) |
| `SG` | レイアウト基準点(LRP) |

正確な定義は、規格書の表 2 を見てください。
