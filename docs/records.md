# よく使うレコード一覧

VCA（OMA / DCS）v3.14 で定義されているレコードのうち、通信の制御と、玉型・処方・レンズ形状に関わるものを抜き出し、日本語で説明したものです。規格には数百のラベルがあります。ここに無いものや正確な定義は、規格書の附属書 A（表 A.1・A.2）を見てください。

- 左右：○ は「右眼の値;左眼の値」の 2 つを持つレコード（値 1 つなら両眼に適用）。空欄は値 1 つだけのレコード
- 単位：D はディオプター。「TIND 基準」はツール屈折率（既定 1.53）で換算したカーブ値

## 通信の制御（インターフェイスレコード）

| ラベル | 左右 | 内容 |
|---|---|---|
| `REQ` | | 要求の種類（`INI`・`TRC`・`EDG` などの文字列、または初期化で割り当てられた要求 ID）。要求パケットの先頭 |
| `ANS` | | 応答の種類。要求と同じ値を返す。応答・データパケットの先頭 |
| `JOB` | | ジョブ番号。初期化以外では 2 番目のレコード |
| `STATUS` | | ステータスコード（0 が正常）。後ろに説明文を付けられる |
| `XSTATUS` | | 左右別の詳しいエラー・警告（`R`/`L`/`B`;コード;説明;`E`/`W`/`N`） |
| `CRC` | | CRC-16 の値（10 進）。パケットの最後 |
| `DEV` | | デバイスの種類 |
| `VEN` | | 機器メーカーの識別子 |
| `MODEL` | | 機種 |
| `SN` | | 機器のシリアル番号 |
| `OMAV` | | 規格のバージョン（例：3.14） |
| `DEF` / `D` / `ENDDEF` | | 自動フォーマット初期化で、受け取りたいレコードの一覧を定義する |
| `TIMEOUT` | | タイムアウトの変更（確認応答;パケット;文字間、秒） |
| `TXTENC` | | 文字列の文字コード（`ASCII` または `UTF-8`） |
| `REM` | | 備考。処理には使わない |

## 玉型（トレース）

| ラベル | 左右 | 内容 |
|---|---|---|
| `TRCFMT` | | 玉型データの見出し（形式;点数;角度モード;眼;対象）。両眼なら眼ごとに 1 つ |
| `R` | | 半径（形式 1 では 1/100 mm の整数）。`TRCFMT` の直後に続く |
| `A` | | 角度（1/100 度）。角度モードが `U`・`C` のとき `R` の直後に続く |
| `ZFMT` / `Z` / `ZA` | | 玉型の立体形状（サグ）の見出し・値・角度。書式は `TRCFMT` と同じ |
| `HBOX` | ○ | 玉型の横幅（外接箱の幅、mm） |
| `VBOX` | ○ | 玉型の縦幅（外接箱の高さ、mm） |
| `CIRC` | ○ | 玉型の周長（平面、mm） |
| `CIRC3D` | ○ | 玉型の周長（立体、mm） |
| `FED` | ○ | 有効径。箱中心から玉型までの最長半径の 2 倍（mm） |
| `FCRV` | ○ | フレームのカーブ（TIND 基準 D） |
| `DBL` | | 鼻幅（左右のレンズ間の距離、mm） |
| `MPD` | | フレーム PD（左右 HBOX の平均＋DBL） |
| `BSIZ` | ○ | 玉型の大きさ補正（横幅で指定、mm） |
| `CSIZ` | ○ | 玉型の大きさ補正（周長で指定、mm） |
| `FBFCIN` / `FBFCUP` | ○ | 加工機用ブロックの位置から玉型の中心までのずれ（内方／上方、mm）。玉型を意図的にずらすときに使い、通常は 0 |
| `ETYP` | | 縁の加工の種類（ヤゲン、リムレス、溝掘りなど。-1 は削らない） |

## 処方

| ラベル | 左右 | 内容 |
|---|---|---|
| `SPH` | ○ | 球面度数（D） |
| `CYL` | ○ | 乱視度数（D） |
| `AX` | ○ | 乱視軸（0〜180 度） |
| `ADD` | ○ | 加入度数（D） |
| `PRVM` | ○ | 処方プリズム量（素材の屈折率でのプリズムディオプター）。薄型化のためのプリズムも含む |
| `PRVA` | ○ | 処方プリズムの基底方向（0〜360 度。頂点から基底へ向かう向き） |
| `IPD` | ○ | 片眼の遠用の中心間距離（いわゆる片眼 PD、mm） |
| `NPD` | ○ | 片眼の近用の中心間距離（mm） |
| `OCHT` | ○ | プリズム基準点の高さ。玉型の下端（外接箱の下辺）から測る（mm） |
| `SEGHT` | ○ | 累進・多焦点のレイアウト基準点の高さ。外接箱の下辺から測る（mm） |
| `BVD` | ○ | 装用時の頂点間距離（mm） |
| `PANTO` | ○ | 前傾角（度） |

## レンズ・ブランク

| ラベル | 左右 | 内容 |
|---|---|---|
| `LIND` | ○ | 素材の屈折率 |
| `TIND` | ○ | カーブ値の換算に使う屈折率（指定が無ければ 1.53） |
| `FRNT` | ○ | ブランクの前面カーブ（TIND 基準 D） |
| `BACK` | ○ | ブランクの後面カーブ（TIND 基準 D、凹面は負） |
| `FRNTR` / `BACKR` | ○ | 前面／後面の曲率半径（mm、平面は 0） |
| `DIA` | ○ | ブランクの直径（mm） |
| `CRIB` | ○ | 削り落とし後の直径（mm）。0 は削らない。負の値はブランク直径から削る量 |
| `BCTHK` / `BETHK` | ○ | ブランクの中心厚／縁厚（mm） |
| `LTYPE` | ○ | レンズの種類（`SV` 単焦点、`PR` 累進、`BI` 二重焦点など） |
| `LMATTYPE` | ○ | 素材の分類（プラスチック、ポリカーボネート、ガラスなど） |

## 仕上がりの厚み

| ラベル | 左右 | 内容 |
|---|---|---|
| `CTHICK` | ○ | 仕上がり中心厚（遠用光学中心で、mm） |
| `THKP` | ○ | 玉型加工後の最も厚い縁の厚み（mm） |
| `THKA` | ○ | `THKP` が生じる角度（度） |
| `THKR` | ○ | `THKP` が生じる点の、箱中心からの距離（mm） |
| `THNP` | ○ | 玉型加工後の最も薄い縁の厚み（mm） |
| `THNA` | ○ | `THNP` が生じる角度（度） |
| `THNR` | ○ | `THNP` が生じる点の、箱中心からの距離（mm） |
